# 予算制約下の多腕バンディット：発表スライドに基づく分析レポート

> **対象**：授業「実践的機械学習II」のグループ発表「予算制約下での最適な学習率と探索率とは？」（全14スライド）。これは発表内容の記録・再整理と、そこから導かれる解釈・限界の検討である。
>
> **必ず区別すること**：発表スライドの数値設定・結果と、現在GitHubで公開している **bandit.py / experiment.py / results/summary.csv** の設定・結果は一致していない。**本レポートの「発表結果」はPPTXに基づく**。現行コードの再現結果は[プロジェクトREADME](../README.md)を参照。

## 要約（Executive summary）

**研究上の問い**：多腕バンディットの学習者が有限の予算しか持たず、破産した場合は探索を続けられないとき、学習率 $\alpha$ と探索率 $\varepsilon$ の適切な組み合わせはどう変わるか。

**実験の構成**：

1. モデル①：1回の報酬を +1／−1 とし、良腕の成功確率0.70、通常腕0.40、初期予算20、最大1,000ステップで、9組の $\alpha,\varepsilon$ を比較。
2. モデル②：稀な当たりに+400、外れに−1の報酬を設定し、初期予算20で短期（スライド9のAは50ステップ）と長期（Bは1,000ステップ）を比較。
3. 追加条件：モデル②について初期予算を1,001に増やし、破産停止の影響を分離する。

**発表に記載された主な観察**：

- モデル①では、試した9条件のうち **$\alpha=0.01,\ \varepsilon=0.02$** が予算期待値・破産率・良腕選択率の3指標で最良、と発表している（スライド7）。
- モデル②でも小さい学習率・探索率は高水準を示す一方、短期条件では別の組み合わせが予算期待値で優位になる局面がある、と考察している（スライド10–13）。
- 初期予算1,001・最大1,000回では**全敗しても予算1が残る**ので破産率が必ず0になり、学習の影響を比較しやすくなる（スライド12）。

**解釈の留保**：これらは指定した候補9組と仮定した報酬環境についてのシミュレーション上の観察であり、$\alpha,\varepsilon$ の一般的な最適性や統計的有意差を示すものではない。

## 1. 背景・問題意識（スライド1–2）

通常の多腕バンディット問題は、未知の報酬分布を持つ複数の腕を試し、報酬の期待値が高い腕を選択することを目指す。

本発表では、これに**資金制約**を追加した。学習のために試す行動自体が損失を生み、予算が0になると追加の試行が不可能になる。したがって、探索・活用のトレードオフに、**早期破産のリスク**が加わる。

検討する仮説は「長い試行期間なら安定した学習と低い探索率が有利になりやすいが、報酬が稀で大きい、あるいは試行期間が短い状況では結果が変わる可能性がある」というものである。ただし、この文章は発表の問題設定・考察から再構成した仮説であり、厳密な事前登録仮説ではない。

## 2. 学習アルゴリズム（スライド4–5）

各腕 $a$ の推定行動価値 $Q_t(a)$ を、選択した腕についてのみ固定学習率で更新する：

$$
Q_{t+1}(A_t)=Q_t(A_t)+\alpha(R_t-Q_t(A_t)).
$$

未選択の腕のQ値はそのまま保持する。

行動選択はε-greedy：

- 確率 $1-\varepsilon$：推定Q値が最大の腕を選ぶ（活用）。
- 確率 $\varepsilon$：全10本から一様ランダムに選ぶ（探索）。

発表で比較する水準は、

$$
\alpha\in\{0.01,0.05,0.20\},\qquad
\varepsilon\in\{0.02,0.10,0.40\}.
$$

全9通りの格子探索である。**低・中・高の各ラベルは、この発表内での相対的な区分**であって、一般的に「最適な学習率の範囲」を規定するものではない。

数式の導出は[理論・公式ノート](theory-and-derivations.md)を参照。

## 3. モデル①：±1報酬の設定（スライド3–8）

### 3.1 環境・実験計画

| 項目 | 発表資料の設定 |
| --- | --- |
| 腕の本数 | 10本（良腕1本、通常腕9本） |
| 良腕の成功確率 | 0.70 |
| 通常腕の成功確率 | 0.40 |
| 報酬 | 成功+1、失敗−1 |
| 初期予算 | 20 |
| 最大試行回数 | 1,000 |
| 学習率 | 0.01、0.05、0.20 |
| 探索率 | 0.02、0.10、0.40 |
| 独立シミュレーション数 | 各条件5,000回 |
| 停止条件 | 予算が0以下、または最大試行回数 |

成功確率 $p$ の腕の期待報酬は

$$
\mathbb E[R]=p\cdot(+1)+(1-p)\cdot(-1)=2p-1
$$

であり、良腕は+0.40、通常腕は−0.20。

### 3.2 評価指標（スライド6）

1. **予算期待値**：各時点での予算を5,000系列で平均し、破産した系列は0として含める。
2. **破産率**：破産した系列数／5,000。
3. **良腕選択率**：良腕を選んだ回数／実際に腕を選んだ回数。

発表資料では「両腕選択率」と書かれた箇所があるが、スライド6の定義から、意図する指標は「**良腕選択率**」と読める。また、各系列の率を平均したのか全系列の回数を合算したのかは、スライドの説明だけでは確定できない。

### 3.3 発表結果（スライド7）

発表スライドには、9条件の予算推移の折れ線グラフ、破産率のヒートマップ、良腕選択率のヒートマップが掲載されている。

**資料で明示された結論**：最も低い学習率・探索率の組 $\alpha=0.01,\varepsilon=0.02$ が、上記3指標すべてで最良だった。

折れ線グラフも、長い試行期間を通じて条件ごとの予算の平均推移に大きな差が現れる様子を示す。発表スライド8では、最も悪い条件でも破産率は約0.46にとどまった、と述べている。

**数値の取り扱い**：発表ファイルには集計データのCSVが添付されていないため、本レポートではグラフの細かな数値を読み取って架空の精密値として転記しない。上記の最良条件・約0.46という値はスライド本文に明記されたもの。

### 3.4 発表の考察（スライド8）

発表では、低学習率・低探索率が優勢だった背景として、

- 最大1,000回という比較的長い試行期間を設定したこと。
- 通常腕の1回当たり期待損失が−0.20と比較的小さかったこと。

を挙げている。

**追加的な解釈**：定常的な報酬環境では、小さな学習率は最近のノイズに過剰反応しにくい。一方、探索率が高いと通常腕を引く機会も増え、有限予算の下では負の期待報酬を重ねやすい。長期に選べるなら、低い学習率でQ値を安定化させる利点が現れ得る。

これは**結果と整合的な仮説**であり、今回の集計結果だけで因果的に証明されたわけではない。

## 4. モデル②：希少・高額報酬への変更（スライド9–13）

### 4.1 設定

| 項目 | モデル② |
| --- | --- |
| 腕の本数 | 10本（良腕1本） |
| 良腕の成功確率 | 0.00833 |
| 通常腕の成功確率 | 0.000925 |
| 報酬 | 成功+400、失敗−1 |
| 初期予算 | A・Bとも20 |
| 試行上限A | **50回（スライド9）** |
| 試行上限B | **1,000回（スライド9）** |
| 追加条件 | 初期予算1,001、最大1,000回 |

期待報酬は

$$
\mathbb E[R]=400p-(1-p)=401p-1.
$$

したがって良腕は **+2.34033**、通常腕は **−0.629075**。

モデル①と違い、成功確率は非常に低いが、成功した場合の報酬が大きい。従って、**期待報酬の大きさと、短期に観測される実際の収益の安定性を区別しなければならない**。

### 4.2 A：短期・初期予算20（スライド10）

図では、平均予算が序盤に低下する傾向、非常に高い破産率、良腕選択率が偶然選択の水準（10本中1本なら約0.1）付近にある傾向が見られる。

**解釈**：当たりがまれな環境で予算20しかないと、十分な正の報酬が出る前に負けが続き、学習途中で破産しやすい。各腕の価値の違いを確実に見分けるには観測が不足しがちである。

これらはグラフに基づく**定性的な記述**であり、元の計算データを再計算したものではない。

### 4.3 B：長期・初期予算20（スライド11）

最大1,000回にすると、条件間の平均予算の推移に大きな差が見える。良腕を学習して継続的に選択できる系列では、高額報酬によって収益が伸びる可能性が生じる一方、破産して途中終了する系列も残る。

発表スライド13では、長期条件で**低学習率・低探索率がとくに高い水準**であったと考察している。

ただし、長期上限を設定しても、予算20のままなら実際にはそこまで到達せず途中で終了する系列がある。したがって「Tが長いから全員が長期学習できる」とは解釈しない。

### 4.4 初期予算1,001で破産をなくす（スライド12）

初期予算を1,001、最大試行回数を1,000とすると、仮に全試行で外れ（−1）でも

$$
B_{\min}=1001-1000=1>0.
$$

よって、**この設定では破産が発生しないことがモデルの構造上保証される**。スライド12も破産率0を示している。

破産を生じさせないことで、腕の価値の学習・選択率の変化と、資金不足による途中終了を切り分けて考えやすくなる。もっとも、学習率・探索率がどの条件で最適かは別途比較が必要である。

### 4.5 希少高額報酬の危険性を定量的に考える（追加導出）

成功確率 $p$、報酬+400／−1では、

$$
\operatorname{Var}(R)=401^2p(1-p).
$$

これは±1の報酬と比較して非常に大きい。特に「期待値が正だから短期間でも儲かる」とは限らない。

例えば、**仮に常に通常腕だけを引く**という単純化した状況では、20回続けて外れる確率は

$$
(1-0.000925)^{20}\approx 0.982.
$$

この20連敗で初期予算20が0になる。**ただし、この約0.982は仮定を固定した説明用計算であり、ε-greedy実験の実測破産率ではない**。実際の方策は選択した腕を逐次変更する。

## 5. 発表の総合的な結論と評価（スライド13–14）

発表者は、比較した条件の範囲で、概して**低学習率・低探索率が有利**だと結論づけている。また、短い試行上限では高学習率や高探索率の条件も予算期待値で競争力を持つ、と述べている。

この結論は**与えた報酬分布・資金制約・試行上限・比較した9条件での観測結果**として読むべきである。「任意の多腕バンディット環境で低学習率・低探索率が最適」と一般化することはできない。

### 解釈で押さえるべき3点

- **学習の速度と分散**：低い$\alpha$は安定性に寄与しうるが、短期・非定常環境では追従が遅くなる。
- **探索の費用**：高い$\varepsilon$は他の腕の情報を増やす一方、通常腕への配分を増やし、破産リスクを高める可能性がある。
- **生存者の選択バイアス**：破産で途中終了するため、時点別の学習状況を「最後まで生き残った系列だけ」で見ると、資金制約が結果に影響する。発表の予算期待値は破産者0を含むと明記されており、ここは適切に扱っている。

## 6. 発表資料内の注意点と、現行実装との差分

### 6.1 スライド9と13の試行上限表記の不一致

スライド9では、モデル②の短期条件 **Aを50回**、長期条件 **Bを1,000回**と記載している。一方、スライド13では短期条件の説明が**「試行回数100回」**となっている。

**どちらの条件が実際の計算に使われたかは、元の実験コードまたは実行ログを確認しないと断定できない。** 本レポートではスライド9の設定表を優先して「A=50」と表記し、食い違いをここに記録した。

### 6.2 スライド14の「最適」の意味

「低学習率・低探索率が最適」という結論は、**探索した有限個のハイパーパラメータ集合における、観測上の優位性**と解釈する。パラメータの全探索・統計的有意差検定・信頼区間の提示はスライドから確認できない。

### 6.3 現行GitHubコードはモデル①の厳密な再現ではない

| 項目 | 発表モデル① | 現行コード |
| --- | --- | --- |
| 良腕成功確率 | 0.70 | 0.65 |
| 通常腕成功確率 | 0.40 | 0.44 |
| 最大ステップ数 | 1,000 | 100 |
| $\alpha$候補 | 0.01／0.05／0.20 | 0.05／0.20／0.80 |
| $\varepsilon$候補 | 0.02／0.10／0.40 | 0.02／0.10／0.40 |

発表スライド7の最良条件 **(0.01, 0.02)** と、現行コードの結果 [summary.csv](../results/summary.csv) における最良条件 **(0.05, 0.02)** は、そもそも異なる条件設定である。

したがって、**発表スライドの実験結果を現行GitHubコードでそのまま再現したと主張してはいけない**。現行コードのCSVは、現在のコードについてのみ正当な再現結果である。

### 6.4 追加の評価上の制約

- 発表のグラフについて、元の生データ・標準誤差・信頼区間がこのPPTXだけでは確認できない。
- 発表資料での乱数シード・各条件の共通環境系列の扱いは明記されていない。
- 良腕選択率の「試行ごとの比率の平均」と「試行全体でプールした比率」を明確に区別する必要がある。

- 既知の良腕を常に選択するoracle方策、全腕一様ランダム方策などの対照群は発表中で明示されていない。

## 7. より強い研究成果にするための追加実験案

これは**発表で既に実施した内容ではなく、今後の改善提案**である。

1. **発表条件の再実装**：モデル①の $p=0.70/0.40,\ T=1000,\ \alpha=\{0.01,0.05,0.20\}$ を独立の設定として再現し、現行コードと混同しない名称・CSV・図表で保存する。
2. **モデル②の再現**：報酬+400／−1、A=50／B=1000／予算1001を別シナリオとして実装する。Aの「50／100」の矛盾は元コードで検証する。
3. **ベースライン追加**：一様ランダム方策、既知の良腕を選ぶoracle方策と比較する。
4. **統計的不確実性を表示**：条件ごとの複数シード平均、標準誤差・信頼区間を追加する。特にモデル②は報酬の分布が裾の重い離散分布であるため、単一の平均値だけでは不十分。
5. **予算と試行上限の感度分析**：初期予算とTを格子状に変え、「探索の機会」と「破産停止」の相互作用を調べる。
6. **選択率の指標定義を統一**：run平均とpooled比率を併記し、試行回数との関連を評価する。
7. **探索方法の比較**：ε-greedy以外のsoftmax、UCB、Thompson Samplingは、実装して初めて比較対象として記載する。
